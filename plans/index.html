General Construction Notes

  1. All work to meet or exceed local residential building code and manufacturer installation instructions. Where this package and code conflict, code governs.
  2. These are built-in millwork assemblies — build, trim, and finish like site-built cabinetry, not like a free-standing metal bunk.
  3. Confirm all rough openings, wall lengths, ceiling heights, outlet/switch locations, window sill heights, and floor level before cutting.
  4. Locate wall studs and, where present, ceiling joists / blocking. All beds are to be positively anchored to framing — never to drywall alone.
  5. Assume walls are out of plumb and floors are out of level. Scribe millwork to walls; shim and level all sleepers/ledgers.
  6. Use kiln-dried, defect-free lumber for structural members. Sheet goods to be cabinet-grade plywood (no particleboard for load members).
  7. Ease / round-over all exposed edges and corners for a kid-safe finish (⅛"–¼" radius min. on reachable edges).
  8. Mattress sizes drive all clear openings — confirm actual mattress dimensions and thickness with owner before framing.
  9. Provide solid blocking behind all rails, ladders, grab points, and shelf standards.
  10. All fasteners in structural connections to be rated screws/bolts (no drywall screws in structural joints).

Ladder / Stair Access & Safety Rail Notes
SheetA6.0Rev 0
Child safety governs. All guardrails, ladder treads, and connections must be built to the stricter of local code and CPSC bunk-bed guidance. FIELD VERIFY openings and heights.
A6.0a — Preferred: built-in box stair w/ storage drawersNTS

Access Concept

  • Preferred: built-in box stair at the right end of the stacked bunk — safer than a ladder for kids and adds drawer storage.
  • Tread depth ≥ 9"–10", riser ≤ 7½"–9", consistent rise/run; treads with a subtle nosing and slip-resistant finish.
  • Continuous graspable handrail on the open side, ~34"–38" above the tread nosing line.
  • Alternate (tight space): integrated angled ladder, rungs ≥ 12" apart, min 3" toe clearance, anchored top & bottom.
  • Every tread/rung anchored to structure with rated screws + glue; no reliance on the drawer boxes for load.

Safety Rail Notes

  • Guardrails on all open sides of the upper bunk; guard top ≥ 5" above the top of the mattress.
  • Continuous guard except at the access opening; access opening ≤ 15" wide.
  • Gaps between guard members and between guard & mattress frame < 3½" so a child cannot slip through or trap a limb.
  • No gap > 3½" anywhere a head/limb could pass (rails, slats, ladder).
  • Foundation/slats must prevent mattress dislodgement; use a positive ledge/lip.
  • Warning label: upper bunk not for children under 6 (per CPSC guidance) — advise owner.
  • Round/ease all edges within reach; recess or cap all fasteners.
References to confirm locally: U.S. CPSC 16 CFR 1213 / 1513 (bunk bed guardrail & opening requirements) and ASTM F1427. These drive guard height, opening sizes, and the < 3½" gap rule. Confirm current requirements with your jurisdiction before build.

All line-voltage work by a licensed electrician per code. FIELD VERIFY existing outlet location on the tall gray wall and confirm circuit capacity before adding loads.

Low-Voltage LED Scope

  • Reading lights: Warm-white (2700–3000K) LED in aluminum channel at each bunk head; individual switch per bed.
  • Under-deck accent: Warm-white strip under each platform & the third bed toe.
  • Gaming mood lighting: RGB/RGBW tape (app/remote) in the cubby nook, behind shelves, and roof-slat cove.
  • All tape 24V, dimmable, in diffused channel — no bare tape visible.
  • Drivers/transformers in a serviceable, ventilated location (e.g., stair base cabinet).
  • Home-run low-voltage wiring; leave service loops; label runs.

Line-Voltage / Devices

  • Keep/relocate existing wall outlet; add convenience + USB/USB-C outlets at bunk heads & the gaming TV wall.
  • Provide switched supply for LED drivers; consider a smart switch/scene control.
  • Gaming TV wall (opposite): recessed outlet + low-voltage/HDMI conduit behind TV location, if layout allows.
  • Do not bury junctions inside sealed millwork — keep accessible.

Carpenter Build Sequence
SheetC1.0Rev 0

Field verify & layout

Measure wall length, ceiling heights (confirm flat-ceiling zone), floor level, outlet, door swing, and slope start. Snap layout lines; mark all studs.

Rough electrical first

Coordinate outlet relocation/additions and low-voltage LED home-runs with electrician before closing any framing.

Base & sleepers

Set and level 2× base sleepers/toe; shim to a level, flat plane. Anchor to floor/wall.

Install ledgers

Lag/structural-screw ledgers to studs at lower, third-bed, and upper deck heights. Verify level.

Set gables & posts

Stand and plumb plywood gables/dividers; scribe to wall & floor; fasten to base and ledgers.

Frame decks

Hang joists, install front rim bands, glue+screw ¾" ply decks. Verify each deck is level and square.

Guardrails & stair

Build the box stair with drawers and install continuous handrail; install upper guardrails (≥5" above mattress, <3½" gaps).

Cubby nook & slat detail

Line the cubby; install oak roof-slat canopy; fit shelving standards.

Face frame & trim

Apply face frames, casings, base, and accent trim; hold consistent ¼" reveals; caulk joints.

LED install

Set channels/diffusers, run tape, connect drivers in serviceable location; test warm + mood scenes.

Finish

Fill, sand, prime, and spray warm white; clear-finish oak accents; install slip-resistant tread finish.

Hardware & punch

Install pulls, drawer soft-close, anti-tip anchors; add mattresses; verify all safety gaps; final clean.

Dry-fit major assemblies before finishing. Keep bed-to-frame connections serviceable (knock-down bolts) so mattresses and platforms can be removed later.

B5.0a — Typical side bookcase (both sides)NTS · FIELD VERIFY height ≤ 75"

Shelving Strategy

  • Both sides: full-height bookcases where depth allows; shallow shelving where tight.
  • Adjustable shelves on 32mm / shelf-pin lines; ¾" ply with hardwood edge band.
  • Optional white-oak veneer/ship-lap accent back in the shelf bays.
  • Closed base cabinet below each shelf tower for hidden storage (no drawers under bed itself).
  • Integrated reading sconce mounted to the inner face of each bookcase, wired concealed.

Carpenter Build Sequence
SheetN4.0Rev 0

Field verify & decide mattress

Measure nook width/depth, ceiling (check slope), window sill/egress, and floor level. Lock the mattress decision (standard vs. custom/short) before anything is cut.

Rough electrical

Set sconce boxes, outlet/USB, and LED low-voltage runs with the electrician.

Build & set bookcases

Build both flanking cases; scribe to walls, rake tops to any slope, plumb/level, and anchor to studs. This establishes the true bed pocket.

Frame the platform

Build the low 2×4 base + sleepers to the measured pocket; shim level; anchor to walls/floor; deck with ¾" ply and vent it.

Trim & skirt

Apply face frames, front skirt/kick, shelf edges, and any oak accents; hold ¼" reveals; caulk.

Lighting

Install sconces and under-platform LED; connect and test dimming.

Finish

Fill, sand, prime, spray warm white; clear-finish oak accents.

Cushions & styling

Install mattress, upholstered back/side cushions and pillows; confirm mattress top sits below the sill; final clean.

Verify the mattress top stays below the window sill after cushions are in — adjust platform height if needed before finishing.
