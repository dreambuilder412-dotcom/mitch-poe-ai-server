# Family House Built-In Bed Plans

A carpenter-ready construction plan package for two custom built-in bed projects
in a residential home. Modern warm family estate style — high-end built-in
millwork, clean trim details, durable kid-friendly construction, navy/charcoal
accents, warm white trim, white oak / Cali oak tone, brass/black hardware.

## What's here

- **`index.html`** — the full construction package (self-contained; open in a browser).
- **`styles.css`** — print-oriented stylesheet (US Letter, portrait).
- **`HANDOFF.md`** — full project handoff summary (context, files, caveats, status).
- **`CARPENTER_BRIEF.md`** — short field-facing brief for the carpenter.

## Two plan sets

**Plan Set 1 — Boys Gamer Room Built-In Triple Bunk** (sheets A1.0–V1.0)
: Built-in millwork bunk system along the tall gray wall (right of the door),
  two stacked beds + a third lower bed, cubby nook with roof-slat detail,
  integrated shelves, LED + gaming mood lighting. Kept clear of the sloped ceiling.

**Plan Set 2 — Window Nook Bed** (sheets B1.0–N5.0)
: Cozy low platform bed (6 ft × 5 ft nook, ~75" ceiling), no drawers under
  (low window), flanking bookshelves, upholstered cushions, reading sconces + LED.

Each set includes floor plan, elevations, section details, framing, trim/millwork,
material list, cut list, fastener/hardware list, finish schedule, electrical/LED
notes, build sequence, and a field-verification checklist. Plan Set 1 also has a
ladder/stair access + safety-rail sheet.

## How to use

1. Open `index.html` in a browser.
2. Click **Print / Save as PDF** (or the browser print dialog) — the layout is
   built for US Letter portrait with one sheet per page.
3. Serve it locally via the project server: `npm start`, then visit
   `http://localhost:3000/plans/`.

## Important

This is a **planning package**, not a stamped engineered drawing set. Every
dimension is preliminary. **FIELD VERIFY BEFORE CUTTING** — complete the
field-verification sheets (V1.0 and N5.0) and confirm all safety/code
requirements with your jurisdiction before ordering or cutting material.
Have a local professional/engineer confirm structural connections for the
upper bunk.
